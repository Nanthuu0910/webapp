# **App Name**: TutorAI Landing

## Core Features:

- Login/Sign Up: Prominent button in the header to allow new users to sign up and returning users to log in.
- Interactive AI Demo: Showcase the AI tutor capabilities through an interactive demo that simulates a tutoring session.
- Feature Benefits Section: Highlight the key benefits of using the AI tutor app.
- AI personalizaton tool: An LLM analyzes user performance on demo problems, in order to personalize recommended AI tutor features to the user.
- Clear Call-to-Action: Encourage users to get started with a clear and persuasive call-to-action button.

## Style Guidelines:

- Primary color: Bright lime green (#32CD32) to convey energy and freshness, reflecting the innovative nature of AI tutoring.
- Background color: Very light green (#F0FFF0), nearly white, provides a clean and calming backdrop that emphasizes the lime green.
- Accent color: Teal (#008080) complements the lime green and adds a modern touch.
- Body font: 'PT Sans' (sans-serif), ensures easy readability for feature descriptions and other content.
- Headline font: 'Playfair' (serif), with an elegant and high-end feel, for impactful headers and short descriptive text. Note: currently only Google Fonts are supported.
- Utilize modern, friendly AI-themed icons and illustrations to enhance visual appeal.
- Ensure a balanced layout with clear sections for each feature and benefit.
- Subtle animations on hover or scroll to enhance user engagement and provide a dynamic feel.
